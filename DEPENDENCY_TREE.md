## Notes

- Export status is authoritative from `NAMESPACE`: 26 exported functions are listed in the first table and 55 internal/helper functions in the second table.
- Both tables use the complete project-function graph. Dependency cells include internal/helper and exported functions; base R and third-party package calls are excluded.
- `extract_subject_id_metadata()` is the requested exported name; `extract_id_subject_metadata()` remains an exported compatibility alias.
- `all_deltas()`, `hysteresis_state()`, and `max_delta_ranges()` are generated Rcpp wrappers in `R/RcppExports.R`; their native implementations were not inspected as R functions.
- Functions defined locally inside top-level functions are not package-level project functions and are not listed as rows or definite graph dependencies.
- Calls through dynamic dispatch, non-standard evaluation, strings, native `.Call()` implementations, and runtime-generated objects were not treated as definite dependencies.
- Unresolved or ambiguous calls: `everything()` in `to_seconds()` is unqualified and not imported in `NAMESPACE`; `setDT()` in `delta_episodes()` is unqualified but `data.table` is imported. Native `.Call()` implementations remain outside R-only static inspection.
- Functions passed to apply-family calls (for example `vapply(x, is_fr_coding, logical(1))`) or bound to a variable (for example `converter <- convertFRFiles`) are counted as direct dependencies; names passed as strings (for example to `parallel::clusterExport()`) are not.
- Per-id frame rates: `metadata$fps` is a scalar when every id shares one rate and a `data.table` with columns `id` and `fps` otherwise. Readers go through `resolve_fr_fps()` and `as_fps_table()`, which accept both; rate precedence per id is stored metadata or file-header attribute, then the `fps` argument, then `infer_fps()`, then 30.
- `resolve_fr_metadata()` is no longer called by any function and remains only as a generic metadata accessor.
- No duplicate top-level function definitions were found.
- Rows with nothing beyond the signature are marked `not statically specified`.
